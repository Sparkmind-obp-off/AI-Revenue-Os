# AI REVENUE OS — UX/UI DESIGN SYSTEM

## Visual Direction
Revenue-first, clear, trustworthy, operational, modern. Dashboard should make the money loop understandable within seconds.

## Information Hierarchy
1. Revenue / conversion outcome
2. Active opportunities and actions
3. Pipeline state
4. Performance
5. Intelligence/recommendations
6. Operational detail

## Core Components
- KPI cards
- opportunity cards
- offer/product cards
- campaign/distribution status
- attribution timeline
- revenue ledger summary
- approval queue
- recommendation cards
- activity/event timeline
- filters by tenant/date/channel/status

## Interaction Rules
- AI recommendation is visually distinct from confirmed business state.
- Destructive/financial actions require confirmation.
- Loading, empty, error, success, and stale-data states are explicit.
- Responsive behavior is required for core operator flows.
- Accessibility: keyboard navigation, semantic labels, sufficient contrast, visible focus.

## Prototype Requirement
Mockup must be polished enough to validate the complete revenue journey before backend implementation.
