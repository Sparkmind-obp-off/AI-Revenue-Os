# AI REVENUE OS — USER JOURNEY & UX FLOW CONTRACT

## Primary Operator Journey
```text
Dashboard
→ Discover Signals
→ Validate Opportunity
→ Select/Create Offer
→ Prepare Distribution
→ Publish/Distribute
→ Track Click/Lead
→ Observe Conversion
→ Verify Commission/Revenue
→ Analyze Performance
→ Review Next Action
```

## UX Principles
- Revenue outcome visible before feature complexity.
- Clear distinction between recommendation and confirmed state.
- Financial state is never presented as AI-generated truth.
- High-impact actions require explicit review/approval.
- Every important state has source/context and timestamp.
- Tenant/unit context is visible where relevant.

## Demo Principle
The prototype should tell the revenue story in one uninterrupted journey without requiring real credentials or production transactions.
