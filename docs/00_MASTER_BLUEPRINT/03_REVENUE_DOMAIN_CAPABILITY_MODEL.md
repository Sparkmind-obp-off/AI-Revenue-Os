## Canonical Lifecycle
`Signal → Opportunity → Offer → Distribution → Lead/Click → Conversion/Order → Commission/Payment → Revenue → Measurement → Next Action`

## Capability Rule
Capabilities become shared core only when semantics are stable, ownership is clear, and reuse is proven by at least two verticals.

## Financial Rule
Money-related state is deterministic, tenant-owned, auditable, and stored using exact decimal/NUMERIC precision with explicit currency and stable identifiers.
