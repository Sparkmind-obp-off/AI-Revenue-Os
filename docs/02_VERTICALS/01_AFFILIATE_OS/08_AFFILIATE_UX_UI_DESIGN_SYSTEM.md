# AFFILIATE OS — UX/UI DESIGN SYSTEM

## Product Feel
Fast, actionable, revenue-focused, trustworthy, and easy for a solo operator to understand.

## Core UI
- revenue KPI strip
- opportunity feed
- product cards
- offer builder
- content preview
- distribution status
- click/conversion funnel
- commission/revenue ledger summary
- performance chart/cards
- AI recommendation queue

## UX Rules
- show source and status for financial metrics
- distinguish AI recommendation from confirmed state
- approvals for high-impact actions
- clear empty/loading/error states
- responsive and keyboard-accessible core flow

## Prototype Visual Goal
A polished dashboard that makes the entire affiliate money loop understandable in one demo session.
